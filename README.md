# 邻里课堂安全协作

泉州 101 个暑期邻里课堂（社区、乡村、企业、园区）安全协作服务的领域资料与最小事件约定，
供市级项目组、点位运营、课程方与企业在统一语义上协作建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件信封、事件目录（48 类）、聚合（12 类）、角色与数据分级枚举。
- `src/domain.ts`：聚合、事件 payload 与事件目录的类型定义（含资质/任务/授权等枚举）。
- `src/validator.js`：信封完整性、事件↔聚合配对、角色与分级校验。
- `data/sample.json`：最小单条样例。
- `data/event-samples.json`：端到端中文样例事件流，覆盖申请→授权→排班→签到→外出→家访→处置→去标识评估。
- `docs/`：
  - [domain-model.md](docs/domain-model.md)：聚合、事件生命周期与核心不变量。
  - [roles-and-access.md](docs/roles-and-access.md)：团干部/社工/志愿者等职责边界与最小知情访问矩阵。
  - [workflows.md](docs/workflows.md)：十一个环节的按职责衔接、读模型与断网/并发边界。
- `tests/`：样例合规、目录一致性、全事件类型覆盖、非法信封拒绝等契约测试。

## 领域边界

- 家庭申请、保障原因、监护授权、接送关系、点位容量、课程风险、人员资质、排班签到、外出活动、家访、事件处置以**不可变事件**衔接；更正只追加后继事件，不原地改写。
- 数据分三级：`operational`（运营必要状态）、`restricted`（家庭敏感资料，仅实际服务的持证人员）、`sealed`（升级后保全记录）。
- 课程方与企业只见履职必需的投影视图；安全线索升级后由社工和监护人接手，运营只见状态；市级项目组只获得去标识连续性数据。
- 资质是排班硬约束：未培训志愿者承担心理团辅、急救或家访的排班会被拦截；人员缺席或资质到期只释放相应任务；断网补签按实际发生时间计、重复不累计。
