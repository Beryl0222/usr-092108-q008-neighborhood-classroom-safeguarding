# 邻里课堂安全协作

本仓库保存该服务的领域资料、事件约定与可运行的领域服务，供业务团队在统一语义上继续建设。

## 内容结构

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/events.js`：事件类型常量与仅追加的事件存储；事件一旦被接收，其标识、发生时间和版本不被原地改写，业务更正产生后继记录。
- `src/service.js`：安全协作领域服务，承载全部业务流程。
- `src/access.js`：分级可见性视图与去标识报表；调用方只读取完成职责所必需的字段。
- `src/domain.ts`：领域类型说明（文档用途）。
- `tests/`：流程测试与契约一致性测试。

## 领域流程（src/service.js）

- **家庭申请与保障原因**：`submitApplication` 登记保障原因、优先保障标识（困境儿童、新就业群体）与上课时段无人照看标记；`confirmEnrollment` 按点位容量录取，满员时重点家庭排在候补前段。
- **监护授权与接送关系**：监护人授权、常态接送人登记均须已授权监护人发起；临时换接送人由监护人发起工单（可覆盖同点位兄弟姐妹），点位指定确认人核实后逐儿童留下 `PICKUP_CHANGED` 记录。
- **人员资质与排班**：团干部、持证社工、高校志愿者先审核后上岗；心理团辅、急救、外出带队、家访为受控任务，须当日有效资质，家访另限持证社工——未培训志愿者无法承担。
- **排班签到**：签到时段按（人员、课程、任务）取并集计时长，断网补签重叠部分不重复累计。
- **外出活动**：须先有持有效急救资质的人员在班才能发布，家长逐儿童授权。
- **家访**：仅限持有效家访资质的持证社工。
- **课程取消**：先为无人照看儿童逐一落实安排（重点家庭优先，能调班则调班，否则登记监护人接回），全部落实后课程才标记取消并释放任务。
- **缺席与资质到期**：缺席只释放当日任务；资质到期只释放到期日起需要该资质的任务。
- **调班**：跨点调班与兄弟姐妹同组调班均由监护人发起并确认，全程事件可追踪。
- **安全线索处置**：线索升级自动指派服务该点位的持证社工并通知监护人；处置记录只追加不改写。

## 分级可见性（src/access.js）

- 家长：`guardianDailyBrief` 查看当天由哪位合格人员照看、是否有外出安排、临时换接送人找谁确认。
- 实际服务的持证人员与监护人：可见儿童完整资料（含保障原因与家庭敏感画像）。
- 课程方、企业联系人、点位运营：只见到课/接送等必要状态与课程计数，看不到家庭敏感资料。
- 市级项目组：`continuityReport` 输出去标识的连续服务报表，判断重点家庭是否真正得到连续服务。
